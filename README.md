# PWS
Polymorphic (automatic window organization) Window System. A CSS-styled WM which comes with it's own Quickshell made shell that can also be styled.
# Is it tiled?
No. Polymorphic window organization is a new tech concept made by me which is tiling, but it basically takes a detour as things automatically place in a similar fashion to KWin and Windows' DWN. There is a tiling mode in the settings, but it is a bit off from Hyprland and others as it waits 5.0000 seconds to wait for another window to open before it builds the tiling setup.
